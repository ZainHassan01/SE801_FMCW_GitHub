# SE-801 FMCW paper draft

Upload this ZIP as a new Overleaf project and compile `main.tex`. The paper uses
`IEEEtran` when that class is available; the locally generated PDF is a
two-column preview built with the source's fallback class.

The paper includes two primary S2 figures: the pooled parent confusion matrix
and outer-fold corruption robustness. Calibration is summarized in a small
table because ECE and Brier score improve after temperature scaling while
negative log-likelihood worsens.

The `supplementary/` folder retains the other four figures and the four
machine-readable comparison artifacts. They are not independent experiments
or additional test sets. S1, S3, S4, and cross-track comparisons are reserved
for the other authors. Confirm all author/affiliation and dataset-citation
metadata before submission.
